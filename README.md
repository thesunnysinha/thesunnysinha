## What I work on

- **Document and knowledge pipelines**: parsing, structured extraction, vector ingestion and RAG.
- **AI agents you can trust**: LangGraph agents with guardrails, human approval and tracing.
- **Deployment tooling**: one CLI from a Docker Compose file to Kubernetes, Helm and cloud VMs.
- **Automation**: small, well-tested tools that remove a repetitive job.

## Featured projects

| | Project | What it does |
|---|---|---|
| 📄 | **[docpipe](https://github.com/thesunnysinha/docpipe)** · [`docpipe-sdk`](https://pypi.org/project/docpipe-sdk/) · [docs](https://docpipe.sunnysinha.online) | Unified SDK and API for document parsing, LLM-based structured extraction, vector ingestion and RAG querying. Pluggable parsers and vector stores, an MCP server, and response caching. |
| 🚀 | **[vm_tool](https://github.com/thesunnysinha/vm_tool)** · [`vm-tool`](https://pypi.org/project/vm-tool/) · [docs](https://vmtool.sunnysinha.online) | Deploy Docker Compose, Kubernetes and Helm projects, manage cloud VMs and Daytona sandboxes, and keep deployment history from one CLI. Can generate a GitHub Actions pipeline. |
| 🕵️ | **[revenue-leakage-agent](https://github.com/thesunnysinha/revenue-leakage-agent)** | LedgerLens: a LangGraph "financial detective" that finds revenue leakage between billing plans and invoices. Proposes fixes but applies them to a sandbox only after explicit human approval. Security, PII, loop and groundedness guardrails. |
| 🎫 | **[build-and-break](https://github.com/thesunnysinha/build-and-break)** | A replayable, file-driven AI pipeline that classifies support tickets, routes low-confidence cases to human review, drafts replies and produces evaluation artifacts. |
| ⏰ | **[cli-alarm-clock](https://github.com/thesunnysinha/cli-alarm-clock)** | A Python CLI to set, list, cancel, snooze and watch alarms, with versioned JSON persistence. |
| 🏭 | **[codecraft-automation](https://github.com/thesunnysinha/codecraft-automation)** | A Docker Compose factory for n8n: zero-touch admin setup, Traefik routing and automatic workflow import on boot. |
| 📬 | **[gmail_processor](https://github.com/thesunnysinha/gmail_processor)** | A Python CLI that fetches Gmail over OAuth, stores messages with SQLAlchemy and applies rule-based actions from a JSON file. |
